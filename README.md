Animal Growth Calculator 

Project Overview

A beginner-friendly Python project designed to calculate animal growth performance indicators using basic animal production data.

Project Objectives

- Collect animal identification and performance data.
- Calculate Weight Gain.
- Calculate Average Daily Gain (ADG).
- Calculate Feed Conversion Ratio (FCR).
- Store animal information in a Python List.

Calculations

- Weight Gain = Final Weight - Initial Weight
- ADG = Weight Gain / Number of Days
- FCR = Total Feed Intake / Weight Gain
